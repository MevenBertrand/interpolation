\begin{abstract}
Interpolation is a cool property in logic. It can be strengthened to a
proof-relevant version, which takes proof terms into account. We give a new
proof of this proof-relevant interpolation in the simply-typed lambda-calculus
with sums, building on ideas from the type theory community, and formalise
it in \Rocq.
\end{abstract}

\section{Introduction}

\subparagraph*{Interpolation for the \stlcp}
\begin{itemize}
  \item Interpolation is cool
  \item It can be made proof-relevant, cf \cite{Cubric1994} for \stlcp
\end{itemize}

\subparagraph*{Interpolation meets normal forms}

\begin{itemize}
  \item The original proof in Čubrić~\cite{Cubric1994} is… not very clean
  \item We can, however, discern that it follows the structure of
    normal forms
  \item By making this characterisation explicit and inductive, we obtain a much
    clearer proof
\end{itemize}

\subparagraph*{Normalisation for commuting conversion}

The key difficulty is that \(\beta\)-normal forms are not enough: interpolation
works well for terms/proofs which satisfy the subformula property, but in
\stlcp \(\beta\)-normal forms do not have this, we need to go further and
normalise with respect to \emph{commuting conversion}.

\subparagraph*{Contributions}
\begin{itemize}
  \item We develop the meta-theory of \stlcp, in particular normalisation
    for a calculus with commuting conversion
  \item We use this as a basis for a new proof of proof-relevant interpolation
    for the \stlcp
  \item All our work is formalised in \Rocq
\end{itemize}

\subparagraph*{A note on the meta-theory} We work in dependent type theory as
a meta-theory. To avoid confusion between object-level and meta-level
judgments, we denote meta-level typing as \(\mty\), and use \(\Set\) and \(\Prop\)
respectively for the meta-level universes of types and propositions –
we will not need more than one universe.

We start with our version of the simply-typed \(\lambda\)-calculus with sums,
hereafter abbreviated as \stlcp,
which we take to contain function types \(\to\), product types \(\times\),
sum types \(+\), and unit and empty types \(\top\) and \(\bot\).
To be able to state an interesting version of interpolation, we must also
include an unspecified set of base types.
To make the result more interesting,
we likewise include a number of constants and equations.
\mlb{Should this go here, or in a separate section?}

\begin{definition}[Language]
  \label{def:lang}
  A \emph{language} \(\lang\) consists of:
  \begin{itemize}
    \item a set of base types \(\base \in \Set\);
    \item a set \(\const \in \Set\) of constants;
    \item types for each constant, \ie
      a function \(\tyof \in \const \to \Ty_{\base}\).%
    \footnote{\(\Ty_{\base}\) is the set of types generated by
    \(\base\), to be defined in \cref{def:types-terms}; formally these
    two definitions should be intertwined.} 
  \end{itemize}
  We write \(\emptyset\) for the empty language, \ie that with no base types nor
  constants.
\end{definition}

\begin{definition}[Types and terms]
\label{def:types-terms}
The definition of types and terms is given in \cref{fig:stlc}.
We decompose types into the \emph{negative} types \(\to\), \(\times\) and
\(\top\), and the \emph{positive} types \(+\), \(\bot\) and base types.
If \(\lang = (\base,\const,\tyof)\) we write
\(\Ty_{\lang}\) for \(\Ty_{\base}\), and similarly for contexts.
When it is not particularly relevant, we omit the language subscript.
\end{definition}

We work with parallel substitutions, the action of which we denote
\(\subs{t}{\sigma}\).
Although we use variable names in terms for clarity,
we rather think them in the de Bruijn style \cite{deBruijn1972}, and
this is the way they are formalised in \Rocq. Accordingly, the
substitution calculus we use is essentially name-free, see \cref{fig:subst} for
the basic primitives. The typing judgment \(\typing{\Delta}{\sigma}[\Gamma]\)
means that \(\sigma\) take a variable \((x : A) \in \Gamma\) to a
term \(\sigma(x) \in \Tm(\Delta,A)\). The primitive's types should be already
rather informative, but let us describe them succinctly: \(\id\) is the identity
substitution, mapping each variable to itself; \(\sigma \pcomp \tau\) is composition,
mapping a variable \(x\) to \(\subs{\sigma(x)}{\tau}\); \(\wk\) drops the last
variable in context, and maps all other variables to themselves;%
\footnote{In named syntax this is a no-op, but we include it
as it changes the context in which a term is considered.} \(\sigma,t\) extends
a substitution \(\sigma\) by mapping the last variable in context to \(t\);
\(\Up \sigma\) maps the last variable to itself, and acts as \(\sigma\) otherwise;
finally \(t..\) is the substitution that maps the last variable to \(t\) and
acts as the identity otherwise. The following substitution rule is admissible:
\begin{mathpar}
  \inferdef[Subst]{\typing{\Delta}{\sigma}[\Gamma] \\ \typing{\Gamma}{\sigma}[A]}
    {\typing{\Delta}{\subs{t}{\sigma}}[A]}
\end{mathpar}

A \emph{renaming} is a substitution mapping variables to variables, and their
collection is denoted as \(\Ren(\Delta,\Gamma)\).

\subsection{Reduction and equations}

The language defined in \cref{fig:stlc}, quotiented by the adequate equational
theory, is the internal language of bi-cartesian closed categories, \ie categories
with finite products, finite coproducts, and exponentials. However, studying
this equational theory is quite unwieldy due to the \(\eta\) laws for sums and
the empty type (see \eg Scherer~\cite{Scherer2017}). Thus, we concentrate
on a less powerful reduction theory, which contains only the rules known
as “commuting conversions” \cite{??}. These are simpler to handle, and suffice to
obtain our ultimate result ---see \cref{rem:eta-sums,rem:interpolation-eta}.

\paragraph*{Reduction}

To factor out commuting conversions, we use a notion of eliminations.
\begin{definition}[Eliminations]
\emph{Eliminations} are given by the following grammar:
\[ e \Coloneqq \sapp{t} \mid \sproj{i} \mid \site{t}{t}\]
We define the \emph{plugging} of a term in an elimination \(\plug{e}{t}\) in the obvious way.
\end{definition}

Reductions, then, are of two kinds: the usual \(\beta\)-reductions, corresponding
to computation ---an abstraction on an argument, the projection of a pair,
and branching on a constructor--- and \emph{commuting conversions}, which “push”
an elimination across another one, the latter of a positive type (\ie \(\bot\) or
a sum). In the case of \(\bot\), the elimination gets completely removed, as it
is in a sense unnecessary: a proof of \(\bot\) can be directly used to inhabit
any type, there is no need to further eliminate it. In the case of the sum,
the elimination gets duplicated in each branch of the if.
\begin{definition}[Reductions]
  \emph{One-step reduction} \(\oredop\)
  is the congruent closure of the rules given in \cref{fig:stlc-red}.
  \emph{Reduction} \(\redop\) is the reflexive, transitive closure of one-step reduction.
\end{definition}

\section{Bidirectional typing, normal forms and the subformula property}

In logic, a key characteristic of derivations is the \emph{subformula property}, satisfied
when where every formula appearing in the derivation is a subformula of some formula
in the conclusion judgment ---either as a hypothesis or conclusion. This
does not hold of arbitrary derivations, but is satisfied by derivations which
are sufficiently normalised, \ie cut-free proofs \cite{Girard1989}.
In a derivation satisfying the subformula property, no formula is ever “invented”,
a powerful structural property with many nice consequences. In
particular, interpolation is usually much easier to prove for cut-free derivation
\cite{??}. One typically obtains interesting properties for all provable
statements by a combination of a cut elimination theorem, which says that every
proof is equal to a cut-free one, and an analysis of cut-free proofs, which can
exploit its more constrained structure, including the subformula property.

For a type theorist, this might seem a bit mysterious. Cut elimination, by
the Curry-Howard correspondence, is well-known to coincide with reduction of
terms viewed as proof witnesses. However, what does the subformula property
amount to? This is much less known, but it can be very helpfully linked to
\emph{bidirectional typing}.%
\footnote{We are not the first to make this connection: it appears
in Dunfield and Krishnaswami's survey on the topic~\cite[Sec. 8]{Dunfield2021},
which attribute it to Pfenning, although we were not able to find a reference
to that effect. The relation between normal forms and the subformula property is also
mentioned by Abel and Sattler~\cite{Abel2019}, although without drawing the
connection to bidirectional typing.}

In bidirectional typing,
which originates from type-checking algorithms \cite{Coquand1996,Pierce2000},
the typing judgment is decomposed into the two, mutually defined
\emph{inference} and \emph{checking} judgments. The operational intuition is
that in the former the type is an output,%
\footnote{\textit{I.e.} the question is ``What is the type of this term?''.}
while in the latter it is an input.%
\footnote{And the question is ``Does this term have this type?''.}
This attention to the flow of information is, in a sense, also what
the subformula property intends to capture: in both cases, the core property
is that type information always comes from somewhere and is never invented.
And in fact bidirectional typing can helpfully be leveraged to exploit
this subformula property, see \eg the strengthening proof in
Lennon-Bertrand~\cite{LennonBertrand2021}.

With this view it is perhaps unsurprising that bidirectional
type systems can be used to structurally characterise normal forms, since,
as we just explained, these correspond to cut-free proofs which have a good
subformula property. This is, however, a remark with powerful consequences:
because bidirectional type systems have a nice, inductive structure, they
give a good basis on which to build clean proof of theorems that rely on
the subformula property, such as interpolation. The remainder of this article
is dedicated to delivering that idea: the rest of this section sets up the
bidirectional characterisation of normal forms, while \cref{sec:interpolation}
derives the interpolation result.

\subsection{A bidirectional characterisation of normal forms}

Our bidirectional type system is given in \cref{fig:bidir}, and was heavily
inspired by the normal forms of Abel and Sattler~\cite{Abel2019}
---suitably modified to not enforce \(\eta\)-long forms. It can be interpreted in two ways.

In the bidirectional mindset, the rules can be read as
a typing algorithm for a fragment of \stlcp. Rules for the inference judgment
\(\infer{\Gamma}{t}{A}\) correspond to settings where it is feasible to infer
the type \(A\) from \(t\), by inferring that of a carefully chosen subterm
(in the case of a negative elimination \nameref{rule:app-b},\nameref{rule:proji-b})
or directly reading it from the
local (\nameref{rule:var-b}) or global (\nameref{rule:cst-b}) context.
Conversely, rules for the checking judgments are those where it is better to check
that a term has a given type. This encompasses constructor forms
(\nameref{rule:star-b}, \nameref{rule:pair-b}, \nameref{rule:lam-b}, \nameref{rule:inl-b},
\nameref{rule:inr-b}), where the checked type is decomposed into its parts
which are used to adequately check the subterms of the constructor;%
\footnote{An acute reader could wonder why we do not make \nameref{rule:star-b}
infer, as \(\star\) can only be of type \(\top\).
Although this could indeed be done, since \(\star\) can
only appear in a checking position because of typing constraints this would
make little difference, and it is more uniform to treat \(\star\)
as a nullary version of pairing.}
any inferring term, which we can also check provided the inferred type coincides
with the checked one (\nameref{rule:demote-b}); and more, interestingly, the
elimination for positive types (\nameref{rule:raise-b}, \nameref{rule:if-b}).
It is rather clear that \(\rai\) cannot be reasonably inferring: how are
we supposed to guess the type \(A\)? For \(\iteop\), we could imagine inferring
the type of both branches, comparing the two, and if they agree infer that type
for the whole pattern-matching. However, our version ends up being better behaved.

In this view, the bidirectional type system arises purely from the will to
type terms without any annotations. To do so, we can only rely on type information
which is already available, either in the context \(\Gamma\), or in the type \(A\)
in the case of checking. This means that all the type information we use
should appear in these in one way or another, which, to reiterate,
is exactly what the subformula property says!

The other approach, coming from normalisation proofs, views the \(\check{\Gamma}{t}{A}\)
judgment as characterising \emph{normal forms}, those which do not reduce further.
When inductively characterising normal forms, it is necessary to mutually define
\emph{neutral forms}, those which can be safely used as the main argument of
an elimination form without creating redexes. Usually, any elimination of a neutral
is again a neutral. But in presence of commuting conversions, this will not do,
as an eliminator on top of \(\rai\) or \(\iteop\) reduces. So in that view too,
it makes sense that these are classified as normal forms but not neutrals.

We can prove that this adequately captures well-typed terms that do not reduce,
\ie that our inductive characterisation indeed captures normal forms in the
more traditional sense. Here we express the theorems only for normal forms,
but they of course also hold for neutrals.

\begin{lemma}[Typability]
  If \(\check{\Gamma}{t}{A}\), then \(\typing{\Gamma}{t}[A]\).
\end{lemma}

\begin{lemma}[Normal forms do not reduce]
  If \(\check{\Gamma}{t}{A}\), then there is no \(t'\) such that
  \(\ored{t}{t'}\).
\end{lemma}

The above two lemmas together show that normal forms are well-typed terms
which do not reduce. The progress theorem below gives a strong
converse to that fact.
\begin{theorem}[Progress]
  If \(\typing{\Gamma}{t}[A]\), then either there is \(t'\) such that
  \(\ored{t}{t'}\), or \(\check{\Gamma}{t}{A}\).
\end{theorem}

\subsection[Normalisation for STLCp]{Normalisation for \stlcp}

In the next section, we prove the interpolation theorem for normal forms only.
To know that it applies more generally, we need to know that every well-typed term
---in the sense of \cref{fig:stlc}--- is related to a normal form. That is, we
need a normalisation theorem. As usual for such theorems, we give a proof by
logical relations, again heavily inspired by Abel and Sattler~\cite{Abel2019},
although our approach does not directly use normalisation-by-evaluation.
At for all logical relation argument, the proof goes by defining a semantic
notion of typing, which implies normalisation, but is strengthened to be stable
under the semantic version of all typing rules.
\mlb{Fix the question of what we use, reduction or equality. For now, equality?}

\paragraph*{Semantic typing}

In a logical relation argument, the key definition is that of values and reducibility,
which go by induction on types. Values at negative types are defined as those
normal forms whose observations are always reducible. That is, a value at a pair
type is a normal form whose first and second projections are values, and a value
at function type is one which takes any value input to a reducible output. This
works fine here. However, things are trickier at positive types. Usually, one
would say that a value at a positive type is given either by a constructor
or a neutral. This will not do here, because we must take into account elimination
of positive types, which are not neutrals. This brings us to introduce
the following inductive notion of covering.

\begin{definition}[Covering]
  A term \(t \in \Tm(\Delta,A)\) is \emph{covered} by the predicate
    \(F \in (\Gamma \in \Ctx) \to \Tm(\Gamma,A) \to \Prop\)
  if:
  \begin{itemize}
    \item \(F(t)\) holds;
    \item \(t = \rai n\) with \(\infer{\Gamma}{n}{\bot}\);
    \item \(t = \ite{n}{b_l}{b_r}\), with \(\infer{\Gamma}{n}{A + B}\),
      and \(b_l\), \(b_r\) are both covered (respectively in \(\Gamma.(x:A)\) and
      \(\Gamma.(x:B)\)).
  \end{itemize}
  We say that a term \(t \in \Tm(\Gamma,A)\) is “covered by neutrals” if it is covered
  by the predicate \(F(\Delta,u) \Coloneqq \infer{\Delta}{u}{A}\), and similarly
  for other predicates on terms.
\end{definition}
This captures terms which have the shape of a case tree,
with nodes decorated by eliminations of neutrals at positive types, and leafs
by terms satisfying the given predicate (in a suitably extended context). It
echoes that of the free cover monad in \textit{op.\ cit.}~\cite{Abel2019}.

The next definition of values and reducible terms goes by induction
on types.
\begin{definition}[Values]
  A \emph{raw value} at a type \(T\) is a term \(t \in \Tm(\Gamma,T)\)
  such that:
  \begin{itemize}
    \item if \(T\) is a base type or \(\bot\) and \(t\) is neutral;
    \item \(T\) is \(\top\) and \(t\) is either neutral or \(\star\);
    \item \(T\) is \(A + B\) and \(t\) is either neutral, \(\inl(a)\) with
      \(a\) value of type \(A\) in \(\Gamma\), or \(\inr(b)\) with \(b\)
      value of type \(B\) in \(\Gamma\).
  \end{itemize}

  A \emph{value} at type \(T\) is a term \(v \in \Tm(\Gamma,T)\) such that:
  \begin{itemize}
    \item if \(T\) is a positive type (base type, \(\bot\), \(A + B\)), \(v\) is
      covered by raw values;
    \item if \(T\) is \(\top\), \(v\) is a normal form;
    \item if \(T\) is \(A_1 \times A_2\), \(v\) is a normal form and \(\proj{i}{v}\)
      is reducible at \(A_i\);
    \item if \(T\) is \(A \to B\), \(v\) is a normal form and for any
      context \(\Delta\), renaming \(\typing{\Delta}{\rho}[\Gamma]\),
      and value \(u \in \Tm(\Delta,A)\), \(\subs{v}{\rho}~u\) is reducible.
  \end{itemize}
  
  Finally, a term \(t\) is \emph{reducible} if there exists a value \(v\) such
  that \(\lred{t}{v}\).
\end{definition}
We extend this definition to substitution pointwise, \ie a value substitution
is a substitution \(\sigma \in \Sub(\Delta,\Gamma)\) mapping each variable
\((x : A) \Gamma\) to a value \(\sigma(x)\) at \(A\).
We use this to define semantic typing.
\begin{definition}[Semantic typing]
  A term \(t\) is \emph{semantically well-typed}, written \(\semty{\Gamma}{t}[A]\),
  if for any value substitution \(\sigma \in \Sub(\Delta,\Gamma)\), \(\subs{t}{\sigma}\)
  is reducible at \(A\) in \(\Delta\).
\end{definition}

\paragraph*{Properties}

Before we can get on to proving the semantic counterparts to the typing rules in
\cref{fig:stlc}, we first need a handful of properties of covers, values and
reducible terms.

\begin{lemma}[Reification]
  Any value is a normal form.
\end{lemma}

\begin{lemma}[Reflection]
  \label{lem:reflect}
  Any neutral is a value. 
\end{lemma}
These lemmas are named by analogy with the reify/reflect functions of normalisation by
evaluation, which respectively map neutrals into the semantic domain and
map semantic values back to normal forms. Proofs go by induction on the
types. For the first, the key ingredient is that a term covered by normal
forms is again a normal form. We need reification in reflection, to handle
reducibility at function types where to conclude that applying the neutral
to a value yields a neutral we need to turn that value into a normal form.

Our next goal is to show that a term covered by reducible terms is itself reducible.
At positive types, this is easy, thanks to the following, which can be read as
the multiplication/join of a covering monad.
\begin{lemma}
  A term covered by terms covered by \(F\) is covered by \(F\).
\end{lemma}

At negative types, however, things are not that simple. Consider the function type:
we assume that at each leaf of the cover we have terms which, when applied to
a value, yield a reducible result; and need to deduce that the whole covered term
is itself reducible, that is, yields reducible result when applied to a value.
The first ingredient is the following lemma, which pushes application
to the leaves of a cover by virtue of commuting conversions.

\begin{lemma}
  \label{lem:push-app}
  If \(f \in \Tm(\Gamma,A\to B)\) is covered by \(F\) and \(u \in \Tm(\Gamma,A)\),
  then \(\red{f~u}{t}\) for some \(t\) which is covered by the predicate
  \[\Delta,t' \mapsto \exists (\rho : \Ren(\Delta,\Gamma)) (f' : \Tm(\Delta,A \to B)).
  (t' = f'~\subs{u}{\rho}) \wedge (F~f')\]
\end{lemma}

We omit similar lemmas for the other destructors: projections, \(\rai\)
and \(\iteop\).
Because pushing the argument to the leaves introduces extra variables
in the context, we must also know that values are preserved by context extension.
The need for this preservation by renaming is what motivates the Kripke-style
quantification over renamings in the definition of values at function
types, without which it would not hold.
For the category theorist, this should be
unsurprising: we wish our normal forms to form a presheaf over
renamings, and the definition of the semantic function type thus mirrors that
of presheaf exponentials.

\begin{lemma}
  If \(v\) is a value of type \(A\) in \(\Gamma\) and \(\rho \in \Ren(\Delta,\Gamma)\),
  then \(\subs{v}{\rho}\) is a value.
\end{lemma}

Putting these together, we obtain:

\begin{lemma}[Reducible cover]
  \label{lem:red-cover}
  A term covered by reducible terms is reducible.
\end{lemma}

With this key lemma in hand, the rest of the semantic typing proofs is
history, and we let the reader consult the \Rocq development for details.
An interesting point to note, though, is that the analogue of \cref{lem:push-app}
for \(\rai\) and \(\iteop\) is not used to prove \cref{lem:red-cover}, but 
instead appear when showing the semantic typing rule for
the eliminators: owing to the polarity of the types, the work for
negative types is in handling the constructors ---where we need \cref{lem:red-cover}---,
while destructors are the hard part for positive types.

\begin{theorem}[Fundamental lemma]
  If \(\typing{\Gamma}{t}[A]\) then \(\semty{\Gamma}{t}[A]\).
\end{theorem}

From \cref{lem:reflect} we get that variables are values at all types, and
thus that the identity substitution is a value substitution. Hence we conclude

\begin{corollary}[Normalisation]
  Any well-typed term reduces to a normal form.
